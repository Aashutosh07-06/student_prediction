Why Netlify showed "Page Not Found (404)" & How to Deploy

EduPredict AI is a Python Streamlit application. Netlify is designed for static frontends (HTML/JS) and cannot run a live Python backend. To run the full interactive ML app with real-time sliders and charts, deploy it on Streamlit Community Cloud (100% Free):

STEP 01
Visit Streamlit Cloud
Open share.streamlit.io and log in with GitHub.
STEP 02
Select Repository
Pick Aashutosh07-06/student_prediction with branch main.
STEP 03
Set Main File
Set file to app.py and click Deploy!

Core Platform Architecture

Multi-dimensional machine learning modeling paired with pedagogical decision intelligence.

🔮

Machine Learning Inference

Multi-variable regression models trained on attendance, study habits, assignments, online courses, and stress index with real-time Grade Tier mapping (Grade A to D).

📈

Longitudinal Trajectory Engine

Chronological performance progression tracking with sequential evaluation delta metrics and dynamic AI diagnostic narratives explaining underlying drivers.

👥

Role-Based Stakeholder Portals

Tailored interfaces for Students (individual progress), Teachers (class audits & batch prediction rosters), and Campus Officials (governance & macro metrics).

📁

Bulk Class Assessment

Batch CSV/Excel upload hub allowing educators to forecast grade distributions across entire student cohorts in seconds.

🗄️

Hybrid Relational DB Engine

Production-grade MySQL storage with automatic fallback to embedded SQLite for seamless zero-config cloud deployments.

🎯

What-If Simulation Sandbox

Interactive parameter tuning enabling students and advisors to simulate the impact of increased study hours or improved attendance.
